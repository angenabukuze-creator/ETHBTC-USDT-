Questions fréquentes (FAQ)

Comment créer un compte ?

Cliquez sur « S'inscrire », remplissez les champs et choisissez un code secret.

Comment me connecter ?

Cliquez sur « Se connecter », saisissez votre numéro de téléphone et votre code secret.

Comment recharger ?

Ouvrez « Recharger / VIP », consultez les niveaux et utilisez les méthodes de paiement affichées.

Comment demander un retrait ?

Ouvrez « Retrait », saisissez le montant et les coordonnées du bénéficiaire. La demande doit être vérifiée.

Les rendements sont-ils garantis ?

Non. Les rendements éventuels comportent des risques et ne sont pas garantis.
